## 1. DYNAMIC ROADMAP GENERATION LOGIC

The **Career Roadmap Engine** builds a multi-phase learning plan dynamically tailored to candidate skill gaps and weekly study hours:

1. **Weekly Study Hours Multiplier**:
   $$\text{Duration Multiplier} = \text{max}\left(0.5, \frac{10}{\text{Weekly Study Hours}}\right)$$
2. **Phase Structure**:
   - **Phase 01: Core Foundations & Technical Prerequisites**: Focuses on foundational gaps (Programming, SQL, Statistics).
   - **Phase 02: Advanced Core Capabilities**: Focuses on core domain gaps (Machine Learning, Deep Learning, Generative AI).
   - **Phase 03: Production Serving, MLOps & Containerization**: Focuses on deployment gaps (FastAPI, Docker, MLOps, CI/CD).
   - **Phase 04: Portfolio Capstone & Technical Interview Defense**: Synthesizes learnings into a published capstone project and interview prep.

## 2. PORTFOLIO PROJECT RECOMMENDATIONS

For each major gap category, the engine recommends targeted projects:
- **Machine Learning Gap**: *End-to-End Customer Churn Prediction Engine*

- **Big Data Gap**: *Distributed Big Data Processing & Streaming ETL Pipeline*
