## Contingency Matrix

| Failure Mode | Symptom | Immediate Recovery Action | Backup View / Action | Jury Spoken Pivot |
| :--- | :--- | :--- | :--- | :--- |
| **A. Backend Server Fails to Start** | Terminal error on port 8000. | Check process with `netstat -ano \| findstr 8000` and kill hanging PID via `taskkill /F /PID <PID>`. Re-run `run_demo.bat`. | Open pre-rendered OpenAPI Swagger documentation or static UI screenshots. | *"While the local server restarts, let us review our evidence architecture documentation."* |
| **B. Frontend Dev Server Fails** | Port 3000 unavailable. | Run `npm run build` inside `frontend/` and preview static build via `npx vite preview`. | Use pre-built static HTML distribution in `frontend/dist/`. | *"We are switching to the production build instance for live demonstration."* |
| **C. Resume Parsing Fails** | 500 error on resume file upload. | Use plain text paste input in Career AI text area instead of file drag-and-drop. | Load sample candidate Jane Doe profile preset from the dropdown menu. | *"We will load our standardized benchmark candidate profile directly into the intelligence engine."* |
| **D. Copilot API Fails or Times Out** | Copilot spinner hangs or returns network error. | Deterministic fallback system automatically intercepts failure and formats structured JSON response. | Point to the structured evidence, reasoning summary, and recommended action cards generated by the fallback system. | *"Notice how our deterministic fallback engine guarantees structured responses even during network interruptions."* |
| **E. Model Lab Prediction Error** | Slider input fails or returns 422 error. | Ensure predictor values stay strictly within 0–100 range. Click "Reset Default Features" button. | Refer to the pre-calculated 5-fold cross-validation metrics table displayed on the Model Lab page. | *"Here you see our pre-computed 5-fold cross-validation metrics and 50-fold repeated CV results."* |
| **F. Dataset Loading Error** | Backend returns dataset missing error. | Verify files exist in `datasets/` folder. Re-run backend server to trigger singleton reloading. | Reference the Dataset Lineage audit matrix in `docs/FINAL_DATA_FREEZE.md`. | *"Our dataset lineage is fully documented and audit-verified across all 17,442 analytical rows."* |

## Emergency One-Touch Reset Command

If the platform environment becomes unstable during live presentation:
```cmd
taskkill /F /IM python.exe /T
taskkill /F /IM node.exe /T
run_demo.bat
```
